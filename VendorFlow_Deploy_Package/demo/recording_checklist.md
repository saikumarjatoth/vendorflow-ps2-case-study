# Screen recording checklist

- [ ] Reset the demo dataset before recording.
- [ ] Open the app in Chrome; hide personal notifications and unrelated tabs.
- [ ] Confirm the screen recorder captures the browser and microphone.
- [ ] Keep the recording under five minutes.
- [ ] Run Successful Vendor live, then Bank Details Mismatch live.
- [ ] Show the processing stages, decision reasons, communication draft and run history.
- [ ] Explain that sample data is synthetic, external checks are not connected, and email is not sent.
- [ ] Review the recording once for legibility and audio before sharing it.
